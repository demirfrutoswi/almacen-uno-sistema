# Sistema de Gestión de Ventas e Inventario - Almacén UNO

Proyecto desarrollado para el Trabajo Práctico Integrador de la asignatura Organización Empresarial.

## Descripción

El proyecto consiste en el desarrollo de un Sistema de Gestión de Ventas e Inventario para Almacén UNO.

El sistema permitirá registrar productos, controlar el stock disponible, gestionar ventas, actualizar automáticamente las existencias y almacenar información relacionada con proveedores.

Su objetivo principal es mejorar la organización de la información y facilitar la administración del negocio.

## Funcionalidades principales

- Registro y modificación de productos.
- Control de inventario.
- Registro de ventas.
- Actualización automática del stock.
- Gestión de proveedores.
- Consulta de productos con bajo stock.
- Generación de reportes de ventas.
