# Módulo de Ventas

Este módulo forma parte del Sistema de Gestión de Ventas e Inventario de Almacén UNO.

## Funcionalidades principales

- Registrar nuevas ventas.
- Seleccionar productos.
- Ingresar cantidades.
- Calcular automáticamente el total.
- Registrar el medio de pago.
- Generar un comprobante de venta.
- Actualizar automáticamente el stock.
