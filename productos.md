# Módulo de Productos

Este módulo forma parte del Sistema de Gestión de Ventas e Inventario de Almacén UNO.

## Datos de los productos

Cada producto contará con la siguiente información:

- Identificador
- Nombre
- Precio
- Stock disponible
- Categoría

## Funcionalidades

El módulo permitirá:

- Registrar nuevos productos.
- Modificar productos existentes.
- Consultar el stock disponible.
- Actualizar las existencias.
